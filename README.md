# 📌 Project Overview

The **Mathematical Calculator** is a web-based application designed to perform quick and accurate mathematical calculations.  
It provides a smooth user experience with responsive buttons, real-time display updates, and an attractive modern UI.

This project is ideal for beginners who want to learn:

- DOM Manipulation
- Event Handling
- JavaScript Functions
- Responsive UI Design
- Arithmetic Logic Implementation

---

# 🚀 Features

✅ Addition, Subtraction, Multiplication & Division  
✅ Responsive and Interactive UI  
✅ Real-Time Display Screen  
✅ Clear Button Functionality  
✅ Keyboard-Friendly Structure  
✅ Beginner-Friendly Source Code
